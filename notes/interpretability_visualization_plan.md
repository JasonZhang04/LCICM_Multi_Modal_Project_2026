# Interpretability and visualization analysis plan

**Project:** Multimodal prediction of aortic root and ascending aorta diameter  
**Prepared:** 31 August 2026  
**Status:** Planning document for review; no interpretability implementation has begun  
**Model snapshot:** `PROGRESS_UPDATE_2026-08-30.md` and the code/results present on 31 August 2026

---

## 1. Executive recommendation

The proposed analysis should have **three**, not two, layers:

1. **Within-modality interpretation:** what image regions, ECG leads/time intervals, and clinical variables influence each prediction?
2. **Fusion-level interpretation:** for a given episode, how much did CXR, EHR, and ECG move the predicted diameter upward or downward, and how is predictive value allocated across modalities at the cohort level?
3. **Explanation validation:** are the explanations faithful to the fitted model, stable, anatomically/physiologically plausible, and genuinely dependent on learned weights?

The third layer is essential for a rigorous paper. A visually convincing heatmap alone is not strong evidence; saliency methods can be insensitive to model parameters and can be mistaken for localization or causal explanations. The analysis should therefore combine exact model decomposition, perturbation/ablation experiments, gradient-based maps, anatomical masks, randomization checks, and stability analyses.

The first implementation should **not** be Grad-CAM. It should be **artifact persistence and exact fusion decomposition**, because:

- the final fusion model is a ridge model, so patient-level signed contributions can be recovered exactly in the output unit (cm);
- this directly answers which modality contributes and in what direction;
- it is inexpensive, readily testable, and does not depend on subjective interpretation;
- the current scripts discard the fold-specific neural models, PCA/scalers, HGB models, and fusion models after producing predictions, so valid held-out CXR/ECG explanations cannot yet be reproduced.

After that foundation, develop CXR interpretation, then ECG interpretation, one module at a time. CXR should use a transformer-compatible attribution method plus anatomical occlusion rather than plain Grad-CAM alone. ECG should use integrated gradients and temporal/lead occlusion targeted primarily to the **ECG contribution to the final fused output**, not merely to the ECG-only auxiliary head.

## 2. What is actually being explained

### 2.1 Current model architecture

The latest model is a staged ensemble, not an end-to-end multimodal attention network. For each anatomical target (root and ascending aorta), the development-set prediction is approximately:

```text
CXR images
  ├─ frozen RAD-DINO cls/aorta-pool/heart-pool + geometry
  │    -> fold-specific PCA + HGB -> per-image diameter -> episode mean d_cxr_frozen
  └─ partially fine-tuned RAD-DINO (last two ViT blocks) + 2-output linear head
       -> per-image diameter -> episode mean d_cxr_ft

EHR: 12 raw/imputed variables and missingness indicators

ECG waveform: 12 x 5000 samples
  -> fold-specific ECGResNet -> 256-d penultimate embedding
  -> fold-specific PCA-32 + standardization

[d_cxr_frozen, d_cxr_ft, EHR features, ECG PCs]
  -> fold-specific ridge -> predicted continuous diameter (cm)
  -> the same continuous score is ranked for >=4.0 and >=4.5 cm endpoints
```

Relevant implementation files are:

- `scripts/train_final_model_episode.py`
- `scripts/train_cxr_finetune_episode.py`
- `scripts/train_ecg_waveform_episode.py`
- `scripts/train_geometry_stack_episode.py`
- `src/multimodal_aorta/models/cxr_encoder.py`
- `src/multimodal_aorta/models/ecg_resnet.py`

The primary development analysis uses the immutable, patient-grouped five-fold partition. Each explanation must be generated by the fold model for which that episode was held out. Root and ascending-aorta explanations must remain separate because they have separate targets and different expected anatomy.

### 2.2 Important implications

1. **Explain the continuous diameter output.** The binary endpoints are derived by ranking the same predicted diameter. Separate “classification saliency” maps would be redundant and could confuse the paper.
2. **There are two CXR paths.** The fine-tuned whole-image ViT and the frozen patch-pool/geometry HGB require different interpretation methods. They should be grouped as CXR at the fusion level but examined separately within the CXR analysis.
3. **The ECG-only head is not the final ECG path.** The final model consumes the 256-d embedding after PCA. Saliency of the ECG head alone does not necessarily explain the ECG component used by fusion.
4. **The fusion model is exactly additive, but inputs are correlated.** Ridge contributions describe the fitted model's mechanics; they do not prove that a modality causes the outcome or contains unique biological information.
5. **Missing ECG currently maps to a zero standardized ECG block.** This represents the mean embedding contribution, not physiological absence of ECG information. Missingness must be displayed explicitly and must not be interpreted as “ECG had no signal.”
6. **Multi-instance CXR aggregation is an equal mean.** The model has no learned image-level attention. Per-image predictions and dispersion are interpretable; invented attention weights are not.
7. **The effective run configuration needs to be frozen.** The latest report adopts CXR PCA-128, while some script defaults still specify 32 and allow runtime overrides. The interpretability manifest must record the actual effective PCA sizes, environment variables, fold map, code revision, input hashes, and model hashes.
8. **Temporal-holdout work is active in the parallel modeling session.** Interpretability method selection should be completed on development OOF data. The quarantined temporal holdout should be used only for a prespecified replication of explanation summaries after the final model and explanation protocol are frozen.

## 3. Scientific questions and estimands

The manuscript should explicitly distinguish the following questions.

| Question | Estimand | Recommended method |
|---|---|---|
| What drove this episode's fitted prediction? | Signed change in predicted diameter relative to a fold-specific reference | Exact ridge decomposition, grouped by modality |
| Which modalities does the fitted model rely on globally? | Distribution of absolute and signed local contributions | OOF contribution summaries with patient-clustered CIs |
| Which modalities contain predictive value, including under redundancy? | Change in OOF performance when a modality is omitted/retrained; fair allocation of total value | Existing nested ablations plus all-subset modality Shapley/dominance analysis |
| What did the CXR branch use? | Spatial attribution and prediction change under anatomical perturbation | ViT attribution + anatomical/matched-control occlusion |
| What did the ECG branch use? | Signed attribution by lead and time, and prediction change under lead/window perturbation | Integrated gradients + lead/temporal occlusion |
| What clinical factors influence fusion? | Signed per-variable contribution in cm and coefficient stability | Exact standardized ridge terms; grouped EHR summaries |
| Are explanations trustworthy? | Faithfulness, randomization sensitivity, repeatability, reproducibility, baseline sensitivity | Quantitative validation battery |

Terms such as “model contribution,” “model reliance,” and “predictive value” should be used deliberately. Avoid “causal effect,” “reason,” “proof of localization,” or “the model looked at” unless the corresponding claim is justified.

## 4. Cross-cutting analysis rules

These rules apply to every module.

### 4.1 Evaluation discipline

- Generate primary explanations **out of fold**: each episode is explained with the model that did not train on that patient.
- Preserve patient grouping in all bootstrap intervals and comparisons because patients may contribute multiple episodes.
- Analyze root and ascending aorta separately.
- Use continuous diameter as the primary target. Treat >=4.0 cm discrimination as secondary and >=4.5 cm as exploratory because events are sparse.
- Use the same eligible episode set for paired modality comparisons. Report an all-eligible analysis and, where ECG is central, a complete-modality sensitivity analysis.
- Do not select explanation methods, regions, smoothing parameters, or example cases using temporal-holdout results.
- Predeclare primary tests before full-scale analysis. Candidate-method pilots are permitted on a small development subset but must not be presented as confirmatory findings.

### 4.2 Uncertainty and multiplicity

- Report patient-cluster bootstrap 95% CIs for cohort-level attribution summaries.
- For repeated measures such as 12 leads or multiple anatomical regions, designate a small set of primary comparisons and use Benjamini-Hochberg FDR for exploratory comparisons.
- Show distributions rather than only means. Attribution values are likely skewed and may have important positive/negative subgroups.
- Report fold-to-fold stability. A large pooled effect with inconsistent fold direction should be treated cautiously.

### 4.3 Reference values

Local additive explanations require a reference. Use the **outer-fold training mean after the exact fitted preprocessing** as the primary reference, because it provides an exact decomposition in cm and never uses the held-out episode. Display the reference prediction as “training-fold reference,” not “normal patient.”

For image/ECG integrated gradients, baseline choice is part of the method and must be tested explicitly. It is not interchangeable with the fusion reference.

### 4.4 Case selection

Do not cherry-pick aesthetically clean maps. Define case strata before viewing explanations, for example:

- high-ranked true dilated episode;
- high-ranked non-dilated episode (false referral at top-5% operating point);
- low-ranked dilated episode (miss);
- typical low-ranked non-dilated episode;
- optionally, the same four strata for root and ascending aorta.

Within each stratum, select the episode nearest a prespecified quantile of prediction/error, or sample reproducibly with a fixed seed. Include AP/PA view and modality availability in captions.

## 5. Phase 0 — artifact and replay contract

### Objective

Make every held-out prediction and explanation reproducible from a versioned set of fold artifacts before interpreting any neural model.

### Required artifacts per outer fold and target

1. **Fine-tuned CXR**
   - encoder and head state dictionaries;
   - target mean/SD used to train the two-output head;
   - training/validation/test patient and episode IDs;
   - image preprocessing configuration and image-cache version;
   - per-image predictions before episode averaging.
2. **ECG**
   - ECGResNet state dictionary;
   - target mean/SD;
   - fold membership and waveform-index version;
   - per-episode embedding and direct-head outputs.
3. **Frozen CXR branch**
   - PCA objects for `cls`, `aortapool`, and `heartpool`;
   - fitted HGB model and ordered feature names;
   - geometry-imputation behavior;
   - per-image predictions and the episode aggregation map.
4. **Fusion**
   - EHR scaler;
   - ECG PCA and scaler;
   - selected ridge alpha, fitted ridge, ordered feature names;
   - explicit ECG-present indicator in the explanation table, even if not a predictor;
   - fold-specific reference vector and reference prediction.
5. **Manifest**
   - code revision and dirty-tree flag;
   - effective configuration, including `K_PCA`, `K_ECG`, `USE_CXR_FT`, and fold mode;
   - hashes or immutable identifiers for cohort tables, fold assignments, embeddings, geometry, waveforms, image cache, and checkpoints;
   - library versions and random seeds.

Prefer an opt-in, namespaced artifact mode such as `SAVE_INTERPRETABILITY_ARTIFACTS=1` rather than overwriting current modeling outputs. Coordinate any edits to active training scripts with the other coding session after the model configuration is frozen.

### Acceptance tests

- Reloaded models reproduce saved per-image/per-episode predictions within a prespecified numerical tolerance (for example, `1e-5` on GPU and tighter for sklearn components).
- Reloaded fusion output equals the saved OOF `pred_final` for every explainable episode.
- Every explained episode's subject ID is absent from its artifact's training IDs.
- Feature count, order, transform shapes, PCA dimensions, and coefficient count match exactly.
- Episode CXR prediction equals the arithmetic mean of its saved image predictions.
- A manifest mismatch fails loudly rather than silently producing a map.

### Deliverable

`outputs/interpretability/<model_version>/manifest.json`, versioned fold artifacts, and a replay-validation report. No scientific interpretation should be published until this phase passes.

## 6. Phase 1 — fusion and EHR interpretation

This should be the first scientific module because it gives exact, readily auditable answers.

### 6.1 Exact local decomposition

For fold-specific ridge model

```text
f(x) = intercept + sum_j beta_j x_j,
```

define the reference vector `r` from the outer-fold training data after preprocessing and compute

```text
reference prediction = f(r)
feature contribution_j = beta_j * (x_j - r_j)
prediction = reference prediction + sum_j feature contribution_j.
```

Group features as:

- **CXR:** frozen-CXR scalar + fine-tuned-CXR scalar;
- **EHR:** the 12 modeled EHR columns;
- **ECG:** all retained standardized ECG PCs;
- optionally, within EHR: demographics, body size, blood pressure, and missingness indicators.

The grouped contributions are in **centimetres of predicted diameter**, so they are directly comparable and retain direction. A positive contribution means “raised this fitted prediction relative to its training-fold reference,” not “increased the patient's true aortic diameter.”

Required numerical check:

```text
abs(prediction - reference - sum(all contributions)) < tolerance
```

for every episode.

### 6.2 Global fusion summaries

Produce, separately for root and ascending aorta:

1. distribution of signed modality contributions;
2. mean and median absolute contribution by modality with cluster-bootstrap CIs;
3. proportion of episodes in which each modality moves the prediction upward versus downward;
4. pairwise correlation of modality contributions, which helps illustrate redundancy/agreement;
5. fold-wise coefficient/contribution stability;
6. contribution distributions stratified by true diameter and by top-5% referral status;
7. sensitivity among ECG-present episodes only.

Use output-scale contribution magnitudes rather than raw coefficient magnitudes. The CXR scalars, standardized EHR variables, and ECG PCs are on different scales, so raw coefficients are not comparable.

### 6.3 EHR-specific interpretation

Because the EHR effect is linear after preprocessing, SHAP is unnecessary for the primary EHR analysis. The exact ridge terms already provide local additive contributions.

Report:

- standardized coefficient forest plots across folds;
- signed and absolute per-variable contributions;
- grouped body-size, blood-pressure, demographic, and missingness contributions;
- coefficient sign/stability across folds;
- simple effect plots showing the fitted linear relationship on the original clinical scale while holding other transformed terms at their reference.

Height, weight, BMI, and BSA are deliberately redundant. Individual coefficients may be unstable even when the body-size group is stable. The main text should emphasize the grouped body-size contribution; individual-variable results belong in the supplement. Missingness-indicator effects should be displayed separately from observed physiologic measurements.

### 6.4 Predictive-value allocation under redundancy

Exact ridge contributions describe model mechanics but do not fairly allocate predictive information when modalities are correlated. Complement them with performance-based analysis:

1. retain the existing nested drop-one/retrain ablations as the primary “does this modality add value?” evidence;
2. fit all eight subsets of `{CXR, EHR, ECG}` under the same folds and preprocessing;
3. calculate group-level Shapley/dominance allocation of improvement over an intercept model, primarily for R2 and secondarily for MAE/AUROC;
4. bootstrap patients and report uncertainty;
5. repeat on the ECG-present common cohort as a sensitivity analysis.

With only three modalities, exact enumeration is preferable to approximate SHAP/SAGE. This analysis can allocate shared predictive value symmetrically, but it still describes predictive value, not causal value.

### 6.5 Figures and tables

- Main figure candidate: root/ascending paired panel with global modality-value allocation and OOF absolute local contributions.
- Main or supplement: four patient-level waterfall plots in cm.
- Supplement: EHR coefficient forest, EHR contribution beeswarm, fold stability, and ECG-present sensitivity.
- Table: modality definitions, mean absolute contribution, signed median, drop-one performance decrement, and Shapley value with 95% CI.

### Phase 1 stop/go criteria

Proceed only if exact reconstruction passes for all episodes and grouped conclusions are not driven by one fold. If coefficient directions are unstable, present prediction contributions and retrained ablations but do not make variable-level mechanistic claims.

## 7. Phase 2 — CXR interpretation

### 7.1 Why plain Grad-CAM is insufficient

RAD-DINO is a ViT-B/16. Original Grad-CAM was designed around convolutional feature maps. A ViT adaptation can reshape the 14 x 14 patch tokens at 224 x 224 input, but the result is coarse and method-dependent. Raw attention weights are also not reliable explanations of output importance.

Therefore use a two-part strategy:

1. **candidate spatial attribution map** adapted to the ViT and continuous target;
2. **model-independent anatomical perturbation** that measures actual prediction change.

The perturbation result should carry more evidential weight than a visually appealing overlay.

### 7.2 Candidate-method pilot

On a fixed development subset, compare:

- ViT Grad-CAM using patch-token reshape and a prespecified late transformer layer;
- gradient-weighted attention rollout or transformer relevance propagation;
- input integrated gradients, with a small set of defensible blurred/reference baselines.

All candidates must target the root or ascending continuous output. For the fine-tuned CXR path, the final-fusion target is the fusion coefficient multiplied by the fine-tuned CXR scalar; this preserves the spatial ordering while correctly recording whether the branch raises or lowers the fused output.

Select the primary map using prespecified quantitative criteria, not visual preference:

- sensitivity to trained versus randomized model weights;
- prediction-faithfulness under patch deletion/insertion or occlusion;
- stability under clinically irrelevant small perturbations;
- cross-fold reproducibility;
- anatomical enrichment relative to mask area and matched random regions.

If no method passes minimum checks, report anatomical occlusion and per-image predictions without claiming a trustworthy pixel-level explanation.

### 7.3 Anatomical validation and occlusion

Use the existing ChestX-Det masks for aorta, mediastinum, and heart. These provide clinically motivated regions but are not ground-truth segmentations of the aortic root or ascending aorta, so the analysis should be called **anatomical alignment/enrichment**, not localization accuracy.

For each map calculate:

- fraction of absolute attribution mass inside each mask;
- enrichment = attribution-mass fraction / image-area fraction;
- peak-attribution region (“pointing” indicator);
- attribution center of mass relative to the aortic/mediastinal mask;
- root-versus-ascending differences.

For perturbation:

- mask or blur the aorta, upper mediastinum, heart, and non-anatomical matched-control regions of equal area/location constraints;
- measure signed change in predicted diameter and absolute change;
- compare target-region occlusion against matched controls with paired patient-cluster bootstrap;
- repeat with more than one replacement strategy (for example, local blur and locally sampled intensity) to assess out-of-distribution sensitivity.

Because the frozen CXR branch already uses segmentation-derived pooling and geometry, mask overlap there is partly built into the pipeline. The strongest anatomical validation is therefore on the **fine-tuned whole-image branch**, which does not consume the masks. Results for the frozen branch should be labeled as descriptive, not independent confirmation.

### 7.4 Fine-tuned CXR branch outputs

- Signed heatmaps for root and ascending aorta, with positive and negative evidence visually separable.
- An unnormalized attribution view for quantitative work and a common, prespecified color scale for comparable case panels.
- Population maps after registering only by the existing standardized image geometry; avoid overinterpreting blurred averages.
- Attribution-enrichment and occlusion-effect distributions with CIs.
- Randomization and augmentation-stability plots.
- Root-versus-ascending paired comparisons on the same radiographs.

### 7.5 Frozen CXR branch outputs

The frozen branch is HGB over three PCA-reduced learned blocks plus 17 geometry variables. Interpret it at two levels:

1. **Block level:** grouped permutation/drop-group analysis for `cls`, `aortapool`, `heartpool`, and geometry, performed within held-out folds. This is the primary analysis because PCA components are not semantically named.
2. **Geometry level:** TreeSHAP or accumulated/local effect summaries for the 17 named geometry features, accompanied by fold/seed stability and correlation-aware caution.

Avoid presenting individual RAD-DINO principal components as clinical features. If TreeSHAP is used, it is descriptive of the fitted HGB, not a fair measure of unique information under correlated inputs.

### 7.6 Multi-instance interpretation

For every episode with multiple CXRs, save and display:

- each image's frozen and fine-tuned predicted diameter;
- equal averaging weight `1/n`;
- within-episode prediction range/SD;
- view (PA/AP), lag from echo, and acquisition metadata;
- per-image attribution summaries.

Analyze whether explanation patterns and predictions are stable across the same patient's images. This is scientifically useful because the current model gains from multi-instance averaging but does not learn which image is “most important.”

### 7.7 CXR stop/go criteria

The primary map should:

- change materially after model-parameter randomization;
- show better deletion/occlusion faithfulness than random maps;
- show acceptable stability under small noise/intensity perturbations;
- reproduce qualitatively and quantitatively across folds;
- avoid being dominated by borders, markers, collimation, or view artifacts.

Failure of a saliency method is a result, not a reason to tune until a pleasing map appears.

## 8. Phase 3 — ECG interpretation

### 8.1 Primary target: the ECG contribution to fusion

For a held-out episode, the final ECG term is

```text
ECG contribution = beta_ecg^T standardize(PCA(embedding(waveform))).
```

PCA, standardization, and ridge are linear. They can be composed into an effective direction in the 256-d embedding and backpropagated through the fold-specific ECGResNet to the 12 x 5000 waveform. This is the most faithful answer to “what ECG signal affected the multimodal prediction?”

Also compute explanations for the ECG-only root/ascending head as a secondary comparison. Agreement suggests the embedding carries similar aortic information into fusion; disagreement is informative and should be reported rather than hidden.

### 8.2 Attribution method

Use signed **integrated gradients (IG)** as the primary gradient method because it provides an explicit completeness property and works with the 1D residual/attention architecture. Recommended baseline analysis:

- primary baseline: zero-mV/isoelectric waveform, justified because inputs are in mV without normalization;
- sensitivity baselines: lead-wise temporal mean or a small set of reference ECGs from the outer-fold training set;
- average IG over small, physiologically negligible Gaussian perturbations for stability, while retaining signed maps;
- verify completeness numerically for every explained recording.

Do not present raw self-attention weights from `AttnBlock` as explanations. Attention can be visualized only as a secondary architecture diagnostic and must not be equated with feature importance.

### 8.3 Clinically readable aggregation

Raw sample-level attribution is too dense for a paper. Derive:

1. **12-lead trace overlay:** positive and negative attribution along the waveform;
2. **lead importance:** sum/mean absolute attribution per lead, with signed contribution retained separately;
3. **lead groups:** limb versus precordial leads;
4. **beat-centered attribution:** detect R peaks, apply QC, and aggregate attribution in a fixed window around valid beats;
5. **phase summaries:** P-wave, QRS, ST-T windows where fiducial detection is reliable;
6. **root-versus-ascending comparison** on the same ECG.

Beat/phase analysis should be conditional on successful fiducial QC; do not force a phase label onto atrial fibrillation, paced rhythms, severe artifact, or failed detections. Report the number and phenotype of excluded ECGs.

### 8.4 Perturbation validation

Validate IG against actual prediction changes:

- occlude contiguous temporal windows at several prespecified widths;
- mask one lead and clinically related lead groups;
- compare the ranking of attribution mass with the ranking of occlusion effects;
- construct deletion curves using highest-attribution versus random windows;
- repeat with zeroing and local interpolation to measure replacement sensitivity.

Single-lead removal can be out of distribution because ECG leads are linearly related. Interpret lead-occlusion results as model sensitivity, not unique physiological necessity. Lead-group and temporal-window analyses are more defensible.

### 8.5 Robustness and specificity

- Cascading parameter-randomization test for the ECG head, attention block, late residual stage, and full network.
- Attribution stability under low-amplitude noise and small temporal shifts.
- Cross-fold distribution stability.
- Compare correct versus high-error episodes without asserting that one group is “more interpretable.”
- Compare root and ascending maps; identical maps may reflect shared aortic signal or lack of target specificity and should be quantified.
- Evaluate whether ECG attribution patterns differ when the fusion ECG contribution is near zero versus large; this prevents strong-looking maps from being shown for clinically negligible branch contributions.

### ECG stop/go criteria

IG must satisfy numerical completeness, depend on trained parameters, and outperform random temporal/lead rankings in perturbation faithfulness. If it fails, retain lead/window occlusion as the principal ECG interpretation and describe saliency as unreliable.

## 9. Phase 4 — multimodal synthesis and publication figures

Only assemble integrated figures after Phases 1–3 are individually validated.

### 9.1 Cohort-level figure

A strong main-text figure could contain:

1. all-subset modality predictive-value allocation (root versus ascending);
2. distribution of exact signed/absolute OOF modality contributions in cm;
3. CXR anatomical occlusion/enrichment results;
4. ECG lead/phase attribution validated by occlusion.

This figure answers three different questions—predictive value, fitted contribution, and within-modality pattern—without pretending they are the same quantity.

### 9.2 Patient-level explanation panel

For each prespecified case:

- true diameter, OOF predicted diameter, fold, and referral rank;
- CXR image(s) with validated spatial attribution and anatomical-mask outline;
- per-image prediction and episode mean;
- ECG trace with signed attribution, plus its total fusion contribution in cm;
- EHR feature contributions;
- final waterfall from fold reference to prediction.

The panel should state when a modality is missing and distinguish “not available” from a near-zero model contribution.

### 9.3 Redundancy visualization

Because the model study concludes that modalities are largely redundant, add a cohort-level plot of pairwise modality contributions or predictions, colored by true diameter. This can show:

- agreement/shared signal;
- cases in which one modality offsets another;
- the small but nonzero waveform-ECG increment;
- differences between root and ascending aorta.

Do not infer biological interaction solely from correlated contributions. Use the existing cooperative-learning and direct cross-attention null results as architectural evidence, and the all-subset analysis as performance evidence.

## 10. Explanation validation battery

Every explanation method should have a short “model card” table containing:

| Property | Test | Minimum interpretation |
|---|---|---|
| Local accuracy/completeness | Reconstruct ridge prediction; IG completeness delta | Required numerical pass |
| Model dependence | Cascading weight randomization | Map must materially change |
| Faithfulness | Anatomy/patch/lead/window deletion or occlusion versus random controls | Important-ranked perturbations should change output more |
| Stability | Small noise, intensity, temporal shift, and repeat runs | Report similarity distribution |
| Reproducibility | Across outer folds and, where available, reruns | Report fold heterogeneity |
| Baseline sensitivity | Alternative IG/reference baselines | Conclusions should not hinge on one arbitrary baseline |
| Anatomical/physiological alignment | Mask enrichment; lead/phase aggregation | Plausibility evidence, not proof |
| Negative controls | Random maps, matched non-anatomical regions, randomized weights | Required |

Metrics can include rank correlation, top-k overlap, structural similarity for maps, deletion-curve area, occlusion effect, and attribution-mass enrichment. No single metric should be treated as a ground truth for explanation quality.

```text
  make_interpretability_figures.py

outputs/interpretability/<model_version>/
  manifest.json
  replay_validation.json
  fusion/
  cxr/
  ecg/
  figures/
```

Suggested tests:

- exact additive reconstruction on a synthetic ridge and real saved episodes;
- correct inverse mapping through scaler/PCA to the ECG embedding direction;
- target-index test distinguishing root from ascending head;
- attribution sign test on a simple known linear waveform model;
- CXR patch reshape/upsampling coordinate test;
- mask-to-preprocessed-image alignment test;
- multi-instance averaging test;
- fold provenance/leakage test;
- deterministic case-selection test;
- randomization test smoke fixture.

All tables used to make figures should be saved as tidy CSV/Parquet files so that every plotted quantity is independently auditable.

## 12. Recommended staged implementation sequence

### Stage 0 — freeze and replay artifacts

**Goal:** persist exact fold models/transforms and reproduce OOF predictions.  
**Decision gate:** no discrepancy beyond tolerance and no fold-provenance violation.

### Stage 1 — fusion/EHR module

**Goal:** exact patient-level contribution tables, global summaries, and all-subset modality value.  
**Decision gate:** exact additivity and stable grouped results.  
**This is the recommended first module for implementation after review.**

### Stage 2a — CXR method pilot

**Goal:** compare a small number of ViT-compatible maps on a fixed development subset with quantitative checks.  
**Decision gate:** choose one primary map or decide that occlusion alone is defensible.

### Stage 2b — CXR population analysis

**Goal:** anatomical enrichment/occlusion, geometry interpretation, multi-instance stability, and figures.  
**Decision gate:** satisfactory randomization, faithfulness, and artifact checks.

### Stage 3a — ECG method pilot

**Goal:** implement fused-target IG, completeness, lead/window occlusion, and baseline sensitivity on a fixed subset.  
**Decision gate:** retain IG only if it passes validation.

### Stage 3b — ECG population analysis

**Goal:** lead/beat/phase summaries, root-versus-ascending comparison, and case plots.

### Stage 4 — synthesis and temporal replication

**Goal:** integrated figures, methods/results text, and application of the frozen explanation protocol to temporal-holdout models.  
**Decision gate:** no post-hoc method changes based on the holdout.

This sequence intentionally produces a reviewable artifact after each stage. We should discuss and approve each stage's estimands, validation criteria, and figures before moving to the next.

## 13. Analyses not recommended as primary evidence

- **Plain Grad-CAM alone:** architecture mismatch and insufficient validation for a ViT.
- **Raw transformer or ECG attention weights:** attention is not automatically output importance.
- **A gallery of hand-selected heatmaps:** vulnerable to cherry-picking and not a cohort-level result.
- **Pixel/lead saliency without perturbation or randomization checks:** visually plausible maps may not depend on learned weights.
- **Raw fusion coefficient magnitude:** incomparable across differently scaled input blocks.
- **Local SHAP on PCA components as a clinical story:** principal components lack direct physiological meaning.
- **Zeroing an entire modality and calling the change its unique value:** this may create out-of-distribution inputs and mishandle correlated modalities. Use retrained subset models for performance value and exact ridge terms for fitted local contribution.
- **Calling mask overlap localization accuracy:** the model was trained with diameter labels, and the available masks are broad anatomical segmentations rather than root/ascending-aorta ground truth.
- **Causal language:** all proposed analyses are associational/model-mechanistic.
- **Explanation-guided changes evaluated repeatedly on the temporal holdout:** that would erode the holdout's intended role.

## 14. Expected manuscript claims if the analyses succeed

Defensible claims would look like:

- “The final ridge permits exact decomposition of each prediction into signed CXR, EHR, and ECG terms in centimetres.”
- “CXR supplied the largest incremental predictive value, while ECG produced a smaller but nonzero continuous-diameter contribution; correlated contribution patterns were consistent with cross-modal redundancy.”
- “Fine-tuned CXR attribution was enriched in prespecified aortic/mediastinal regions and occluding these regions altered predictions more than matched control occlusions.”
- “Fusion-target ECG attribution concentrated in reproducible lead/time patterns and those patterns were supported by lead/window perturbation.”
- “All neural explanations passed model-randomization and stability checks.”

If the validation tests do not succeed, the honest claim should be narrower—for example, exact fusion decomposition and region/lead perturbation results without asserting reliable pixel- or sample-level saliency.
