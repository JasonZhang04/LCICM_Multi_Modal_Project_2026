# Repo cleanup — 2026-09-20

Done on branch `v4-cleanup_final_design`, ahead of the pipeline / architecture /
training redesign. Everything below is **recoverable from git history**; nothing
was permanently deleted.

## What moved

**`notes/` now holds only documents that describe the current system.** Eight
superseded documents moved to `notes/archive/`, which carries a README saying why
each was archived and warning against planning from them. The dividing line is the
**2026-07-23 audit**, which replaced the 522-patient triple cohort with the
~15k-patient episode cohort. Anything written against 522 patients is archived,
because its numbers are not comparable to current results.

Deliberately **not** archived: `notes/ECG/ecg_encoder_aortic_multimodal_implementation_guide.md`.
Its cohort framing is stale, but its survey of public pretrained ECG encoders
(ECGFounder, ECG-FM, xECG, ECG-CPC) is the reference for Stage B/C, which need
exactly one frozen shared encoder.

## What was added

- **`notes/experimental_record_index.md`** (mirrored to `outputs/README.md`):
  indexes all 64 run directories by cohort era, so it is possible to tell which
  numbers are safe to quote. Also marks the quarantined holdout runs and flags
  that `a7_comparison` was measured through the broken ECG basis.
- **Rewritten `README.md`**: it described a "transformer-based fusion model" and
  pointed new readers at an abandoned past attempt. It now states the real
  architecture, the episode unit, the nested-CV estimate, and the two open defects.

## Still outstanding — needs a human decision

`outputs/` era-A/B runs (~15 GB) and
`scripts/echo_infer_AD/results/checkpoints/` (~8 GB, 7 epoch checkpoints from an
EchoJEPA fine-tune).

Verified: **no current script loads any of them**, and they are outputs of
superseded code, not reproducible inputs to the plan. Deleting the `.pt` files
while keeping every `results.json`, `train.log` and `training_log.csv` would
reclaim ~23 GB of the project's 74 GB and lose nothing the record depends on.

This was left undone because `outputs/` is gitignored, making it the one
irreversible deletion in this cleanup. It needs an explicit go-ahead.
